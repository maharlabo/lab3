# Лабораторная работа №3
## Тема: библиотечные книги
## Установка
```shell
git clone https://github.com/maharlabo/lab3.git
cd lab3
python -m venv .venv
.venv/Scripts/activate.ps1
pip install -e .
```

## Запуск
```shell
python -m src.library_books
```
или
```shell
python -m pytest
```

## Что реализовано
1) Хранение каталога в JSON
2) Добавление, получение, удаление книг
3) Поиск по части имени и категории
4) Получение количества книг в каталоге
5) Итерирование каталога (в алфавитном порядке по имени)
## Тесты
1) Создание валидного объекта
2) Передача пустого поля при создании объекта
3) Передача недопустимого года изготовления при создании объекта
4) Передача неверного id при создании объекта (должен соответствовать формату isbn)
5) Добавление, получение и удаление элемента
6) Передача объекта с существующим в каталоге id
7) Поиск по категории и части имени
8) Итерирование
9) Roundtrip JSON
10) Загрузка из повреждённого файла
11) Неверный формат в файле
12) Проверка изменений при загрузке из повреждённого файла
